# Bootloops MVP

**Bootloops** is a creative technology lab for conscious self-mastery, music, interactive tools, and resilient living.

**Mission:** Bootloops builds playful tools, music, and open learning experiences that help people reboot their minds, skills, communities, and technology.

## What is included

- `index.html` — Homepage, mission, Living Orb demo, featured experiments
- `lab.html` — Interactive tools and maker/local-AI projects
- `sound.html` — Music, albums, EPs, and creative releases
- `learn.html` — Free learning pathways and Quantum Human concepts
- `reboot.html` — Practical resilience, self-mastery, local-first technology, and community resources
- `css/style.css` — Complete responsive dark cyber-organic design system
- `js/main.js` — Animated Living Orb canvas with Calm / Focus / Surge modes

## Run locally

Open `index.html` directly in a browser, or run:

```bash
cd bootloops-mvp
python3 -m http.server 8000
```

Then visit: http://localhost:8000
